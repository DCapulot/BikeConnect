# 🚲 BikeConnect

> Bicicletas compartilhadas que funcionam **mesmo sem internet móvel**.

O **BikeConnect** é um projeto acadêmico de modelagem de negócios para uma plataforma de bicicletas compartilhadas que permite a retirada da bike sem depender de conexão de dados móveis. A comunicação entre o celular do usuário e a estação acontece localmente, via **Bluetooth Low Energy (BLE)** e/ou **Wi-Fi local**.

Este repositório reúne todas as etapas de construção do projeto, da identificação do problema até o Business Model Canvas.

## 💡 A ideia

Sistemas tradicionais de bicicletas compartilhadas dependem de internet móvel para desbloquear a bike. Em locais com sinal fraco ou inexistente (parques, campi, condomínios, áreas afastadas) isso torna o serviço instável ou inutilizável.

O BikeConnect resolve isso com uma abordagem de **comunicação local** entre o aparelho do usuário e a estação, mantendo a experiência de retirada simples e confiável.

## 🏢 Modelo de negócio

O BikeConnect foi pensado como uma **empresa de tecnologia B2B**, com solução integrável a sistemas já existentes. Clientes potenciais:

- Operadoras de bicicletas compartilhadas
- Prefeituras
- Universidades
- Parques
- Condomínios
- Empresas
